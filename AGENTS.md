# Overview

## Projects
The project name is SplitIt!
Project allows users to create projects and invite others to join.
Everyone in the project can add an expanse and split it with others.
Ultimately SplitIt! tells who owe to whom and how much to settle down the project.

## Personal
SplitIt! also has embed personal expense tracker. Every project expense is automatically propagated to your personal expenses on amount of the split you had to cover.
